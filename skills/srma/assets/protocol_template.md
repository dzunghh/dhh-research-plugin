## 3. Searches
- Databases and platforms (e.g. MEDLINE via Ovid, Embase via Ovid, CENTRAL, CINAHL…)
- Registers (ClinicalTrials.gov, WHO ICTRP); grey literature; citation chasing; contacting authors
- Draft MEDLINE strategy (append in full); PRESS peer review planned (Y/N)
- Search date limits and rationale; plan for an update search before the final analysis

## 4. Study selection and data collection
- Screening tool (Rayyan / Covidence / other); calibration pilot; dual independent screening at both stages; how conflicts are resolved
- Extraction form items; piloting; dual extraction or extraction plus verification; source-quote rule; contacting authors for missing data
- Conversions planned (SD from SE/CI, median/IQR → mean/SD method, combining groups, log HR derivation)

## 5. Risk of bias
- Tool per design (RoB 2 / ROBINS-I / ROBINS-E / JBI prevalence / QUADAS-2); effect of interest (assignment vs adherence) for RoB 2
- Two independent assessors; overall-judgement rule
- How RoB enters the synthesis (pick one, Cochrane 7.6.2): restrict to low-RoB studies with sensitivity analysis / stratify / pool all + GRADE / bias-adjusted

## 6. Synthesis
- Criteria for pooling (when a meta-analysis is done vs SWiM narrative synthesis)
- Effect measure per outcome (RR / OR / MD / SMD / HR / proportion / sens–spec)
- Model: random effects, REML τ², Hartung–Knapp CI (ad hoc "se"), 95% prediction interval; proportions: GLMM logit; DTA: bivariate
- Heterogeneity: τ², I², prediction interval; pre-specified subgroups (≤ 3, with expected direction and rationale); meta-regression only if k ≥ 10 per covariate
- Sensitivity analyses (e.g. low-RoB only, imputation choices, common-effect model, leave-one-out)
- Small-study effects: funnel plot + Egger/Harbord only if k ≥ 10
- Unit-of-analysis issues (cluster, crossover, multi-arm)
- Missing data handling

## 7. Certainty of evidence
- GRADE outcomes for the Summary of Findings table (≤ 7, listed in order of importance)
- Assumed comparator risk source for absolute effects
- Decision thresholds / minimal important difference for imprecision

## 8. Dissemination
- Reporting guideline: PRISMA 2020 / PRISMA-ScR / PRISMA-DTA / MOOSE
